# htmlppt

**一个零依赖、零框架、零构建的网页版 PPT 放映器**——把一页页纯 HTML 放进 `pages/`，浏览器打开就是带翻页、字幕、缩略图跳转的演示。

## 为什么用它

- **AI 做 HTML 比做 PPT 强得多。** 大模型代码能力提升、成本下降，HTML/CSS 能做出比传统 PPT 更精美的版式与动画；而 python-pptx / Office 自动化对 AI 来说壁垒高、上下文消耗大，很难在较短上下文里保持稳定质量。
- **所以本项目把演示「降维」。** 放映器一次写好、永远不动；创作只剩一件事——写一页纯 HTML。这正是 AI 最擅长、质量最稳的工作形态。你对 Agent 说一句「帮我做套关于 X 的演示」，它就能按统一规范产出分页，放进 `pages/` 即可放映。
- **分页是独立文件。** 每一页都能单独打开、单独发给别人，不依赖放映器；不联网也能用。

## 三分钟上手

```bash
python serve.py        # Windows 也可双击 serve.bat
```

浏览器打开 `http://127.0.0.1:8000/` 即开始放映。加一页 = 往 `pages/` 放一个 `序号-页名.html`，再跑 `python generate_index.py`。

> **不要用 Chrome / Edge 双击 `index.html`**：同源限制会让方向键、空格和右键菜单失灵（Firefox 双击没问题）。用上面的 `serve.py` 就一切正常。

## 功能一览

- `←` `→` `↑` `↓` 翻页，空格逐句翻字幕（单击下一句、双击上一句）
- 字幕条可拖动，三档显隐（持久显示 / 悬停显示 / 持久隐藏），选择会被记住
- 右键玻璃菜单：显示字幕、字幕显示方式；在**页码上**右键弹出**真实缩略图**跳转面板，单 / 双 / 三列可切
- 控件全是靠近才浮现的毛玻璃卡片，平时不挡内容

## 文件地图（30 秒版）

| 你想…… | 动哪里 |
| --- | --- |
| 放映 | `python serve.py` |
| 加页 / 改页 | `pages/序号-页名.html` + `python generate_index.py` |
| 改字幕 | `subtitle.txt`（一行一句）+ 跑构建 |
| 换整套演示的主题样式 | 只改 `pages/_template.html` 的 `:root`，再整块同步到各分页 |
| 让 Agent 帮你做演示 | 把仓库给它，它会读 `AGENTS.md` 与本文件第二部分 |
| 改放映器本体 | 先通读 `AGENTS.md`（含不可破坏的不变量） |

# 第一部分 · 给用户

## 1. 这是什么

一个不用安装、不用联网的网页版 PPT 放映器。把做好的 HTML 页面放进 `pages/` 文件夹，浏览器里就能全屏放映，带翻页、字幕和页面缩略图跳转。

## 2. 启动（必须这样做）

| 系统 | 操作 |
| --- | --- |
| Windows | 双击 `serve.bat`；或命令行运行 `python serve.py` |
| 任意系统 | `python serve.py`，然后浏览器打开终端里显示的地址（默认 `http://127.0.0.1:8000/`） |

按 `Ctrl+C` 停止服务。端口被占用会自动往后顺延，还会打印一个局域网地址，手机同网也能看。

> **不要用 Chrome / Edge 双击 `index.html`**：那样打开后方向键、空格和右键菜单会失灵，只有翻页按钮能用。这是浏览器的同源限制，不是坏了。用上面的 `serve.py` 就正常。Firefox 双击打开则没问题。

## 3. 放映时能做什么

| 操作 | 效果 |
| --- | --- |
| `←` `↑` / `→` `↓` | 上一页 / 下一页 |
| `空格` 单击 | 下一句字幕（约 0.3 秒后） |
| `空格` 快速连按两次 | 上一句字幕 |
| 鼠标靠近屏幕左右边缘 | 浮出翻页按钮；靠近顶部中间浮出页码 |
| 鼠标移到字幕条上 | 字幕**正上方中央**浮出一对小箭头按钮（‹ 上一条 / › 下一条），位置不随字幕长短移动 |
| 拖动底部字幕条 | 把字幕挪到顺眼的位置 |
| 在画面空白处右键 | 「显示字幕」 |
| 在字幕条上右键 | 字幕三档：持久显示 / 悬停显示 / 持久隐藏（会记住选择） |
| 在**顶部页码上**右键 | 弹出缩略图面板，点任意一页直接跳过去 |
| 缩略图面板**右上角三个图标** | 切换单列 / 双列 / 三列展示（会记住选择；页多时面板内部滚动，右缘外侧会出现一条悬浮滑轨，可拖动、也可点空白处跳转） |
| `Esc` | 关掉右键菜单 |

## 4. 加一页 / 改字幕

1. 把做好的 HTML 放进 `pages/`，文件名用 **`序号-页名.html`**，例如 `3-目录.html`、`04-方案对比.html`。序号只用来排序，位数不限、可以跳号，放映时会挤紧成 1、2、3…
2. 改字幕就编辑 `subtitle.txt`，**一行一句**。
3. 双击 `generate_index.py.bat`（或运行 `python generate_index.py`）。刷新浏览器即可。

页名会显示在缩略图跳转面板上，**尽量短**（建议 8 个汉字以内），太长会被省略号截断。

## 5. 哪些文件别动

| 文件 | 说明 |
| --- | --- |
| `pages/*.html` | 你的幻灯片，随便加、随便改 |
| `subtitle.txt` | 字幕，随便改 |
| `js/pages.js`、`js/subtitle.js` | **自动生成，手改会被覆盖**。改完数据源跑一次构建即可 |
| `index.html` | 放映器本体，一般不用碰；别删掉里面两行 `<script src="js/...">` |
| `AGENTS.md` / 本文件 | 技术规范与制作规范，改之前先读一遍 |
| `MEMORY.md` | 历史失误与坑位档案，出问题时按现象查 |
| `.ignore/` | 归档备份，不用管 |

## 6. 出问题先看这里

| 现象 | 原因 / 处理 |
| --- | --- |
| 方向键、空格、右键菜单没反应 | 用 Chrome/Edge 双击打开了 `file://`。改用 `python serve.py` |
| 新加的页不出现 | 文件名没有序号（如 `template.html` 会被忽略），或忘了跑 `generate_index.py` |
| 跳转面板里的缩略图全黑 | 分页 HTML 没写页面背景。按第二部分模板建页即可 |
| 页码和文件名里的编号对不上 | 正常：显示的是排序后的顺序号，不是文件名编号 |

# 第二部分 · 给 Agent / AI：分页制作规范

> **最短路径**（细节按需查对应小节）：
> ① 填**页序大纲**与**术语表**（§4.1 / §4.2），不填大纲不许开写 →
> ② 复制 `pages/_template.html` 造 `pages/<序号>-<页名>.html`，只改 `<title>`、`<main>` 文字、`slide-foot`（§2），**STYLE-BLOCK 逐字节保留**（§3）→
> ③ `python generate_index.py` + `--check` →
> ④ `python check_style.py` + 禁用项 grep（§5）→
> ⑤ **有浏览器权限时**：`python serve.py` 起服务逐页实测——无滚动条、右键页码缩略图非全黑、版式一致（§6）。推理不算证据，采样才算。

## 0. 先确认边界

放映器的设计目标是「**一个单独的简约 HTML 文件，用来放映分页 HTML**」。由此有两条铁律，制作分页时不能碰：

1. **幻灯片是独立文件**，可以单独打开、单独发给别人。所以样式必须由分页**自带**，不能靠放映器注入。
2. **放映器不改写、不注入幻灯片**（`AGENTS.md` 第七节不变量 1 / 10）。`generate_index.py` 只扫文件名生成 `js/*.js`，对 `index.html` 零写入，也不会往分页里塞任何东西。

> 「不给幻灯片注入脚本」约束的是**放映器 / 构建脚本的行为**，不是「分页自己不能带样式」。Agent 在创作新分页时写入内联 `<style>` 属于正常创作，且是本方案的基础。但**任何 `<script>` 仍然禁止**。

## 1. 项目结构与数据流

```
htmlppt/
├── index.html              放映器：样式 + 骨架 + 交互；用 iframe 铺满视口加载分页
├── serve.py / serve.bat    本地 HTTP 服务（同源必需）
├── generate_index.py      构建脚本：扫描数据源 → 整份写 js/*.js
├── check_style.py         样式块一致性校验（本方案配套工具）
├── subtitle.txt           字幕源，一行一句
├── js/pages.js            生成物：SLIDE_PAGES / slideFiles / slideTitles
├── js/subtitle.js         生成物：SUBTITLE_TEXT
├── pages/                 分页目录：放什么就放映什么
│   ├── _template.html     ← 样式唯一真源（下划线开头，扫描时自动忽略）
│   └── N-页名.html         正式分页
├── AGENTS.md              架构与不变量（权威）
├── MEMORY.md              历史失误与坑位档案
├── README.MD              本文件
```

```
pages/ 文件名 + subtitle.txt
        ↓  python generate_index.py（整份渲染、原子写、零写入 index.html）
js/pages.js + js/subtitle.js
        ↓  两行 <script src>（顺序硬约束：subtitle 在字幕解析前，pages 在 loadSlide 前）
index.html 运行时 → iframe src="pages/<file>" 逐页加载
```

**iframe 隔离是一切坑的根源**：幻灯片铺满视口，父页面收不到幻灯片区域内的 `mousemove` / `keydown` / `contextmenu` / `mousedown`；放映器在 `iframe.onload` 里把监听注入 `contentWindow.document`，前提是同源。分页本身不要试图和父页面通信，也不要假设自己能拿到放映器状态。

## 2. 分页文件的制作约束

### 2.1 命名与关联

| 约束 | 说明 |
| --- | --- |
| 文件名 | `序号-页名.html`。序号为自然数、位数不限（`1`、`03`、`0006` 都行），只按数值排序 |
| 分隔符 | 半角/全角横线、下划线均可，两侧允许空格 |
| 显示序号 | **由排序后的数组下标决定**，空号自动挤紧；与文件名编号无关 |
| 页名 | 既是文件名的一部分，也是缩略图面板 `.page-name` 的标签（卡片宽随列数档位：96 / 148 / 302px，超长省略），务必短 |
| `<title>` | 与文件名页名保持一致。页名兜底链是「文件名 → `<title>` → 第一个 `<h1>` → 空」 |
| 会被忽略 | `_` / `.` / `~$` 开头、`index.html`、`template.html`、非 `.html/.htm`、无序号文件 |
| 重号 | 属歧义，脚本按文件名定序并警告，`--strict` 直接报错 |
| `js/pages.js` | 生成物，**禁止手改**。加页 = 放文件 + 跑构建 |
| 页间链接 | **不要写死别页的文件名**（改名即断链）。需要导航用文字提示，如「下一节：方案对比」 |
| 字幕 | `subtitle.txt` 一行一句，与分页是**两套独立索引**（空格逐句翻、方向键逐页翻），不会自动跟页。做逐页字幕须在大纲里写清每页对应哪几句 |

### 2.2 内容结构

每页固定三段骨架，只用模板给定的 class：

```html
<main class="slide" data-role="content">
  <header class="slide-head">
    <p class="kicker">章节名</p>
    <h1>本页唯一主张</h1>
    <p class="lead">承接上页 / 点明本页要解决的问题</p>
  </header>
  <section class="slide-body"><!-- 受控组件 --></section>
  <footer class="slide-foot">
    <span class="doc">文档名</span>
    <span class="chapter">章节名</span>
  </footer>
</main>
```

`data-role` 取 `cover` / `agenda` / `section` / `content` / `summary` / `end` 之一，只切角色、不改样式表。

**页脚禁止写页码**（包括「第 3 页」「3 / 12」）。放映时的序号是数组下标，插一页、改个文件名就全错。页脚只放文档名与章节名。

### 2.3 禁止清单

| 禁止 | 理由 |
| --- | --- |
| `<script>` | 放映器不注入、分页也不带；幻灯片可能被单独打开，脚本无宿主 |
| 外链 `http(s)://` 资源（CSS、字体、图片、CDN） | 离线底线 + 单文件分发性 |
| 行内 `style="..."`、新造 class、页面内另写 `<style>` | 样式漂移的主要来源 |
| 写死颜色 / 字号 / 间距数值 | 必须走 `:root` 令牌，否则换主题时逐页改 |
| 写死页码、写死别页文件名 | 见 2.1 / 2.2 |
| 内容超过一屏 | iframe 会出现滚动条，放映即不合格 |
| 深色底 | 放映器的按钮、页码、字幕、菜单都是深色玻璃，深色页会撞色看不清 |

### 2.4 与放映器 / 缩略图的耦合（容易漏）

- **必须显式写 `html,body{background:...}`**。裸 HTML 片段在 iframe 经 `transform:scale()` 合成缩略图时，根背景会被当透明，透出深色面板 →「缩略图全黑」（`MEMORY.md` 错误 10）。模板已写好。
- **字号用 `clamp() + vw`**，不要固定 px。主放映时 iframe 尺寸随窗口变化，缩略图则固定 1280×720；固定字号在两种尺寸下观感不一致。
- **浅色底**：与深色玻璃控件形成对比，也保证缩略图可读。
- **缩略图比例**：面板把分页按 1280×720 渲染，再按列数档位等比缩到 96 / 148 / 302 宽。缩略图里只看版式与色块，别指望小字可读，标题要足够大。

## 3. 样式统一方案

### 3.1 为什么不用共享 CSS 外链

最直觉的做法是 `pages/ppt.css` + 每页一行 `<link>`。但它破坏「**单独发一个 HTML 给别人**」——脱离目录就掉样式，而这是项目初衷。反过来，让放映器或构建脚本把样式注入分页，又违反「不改写幻灯片」。

因此方案定为：**每个分页内联同一份 `<style>`，这份样式只有一个真源**。

| 代价 | 对冲手段 |
| --- | --- |
| 样式在多页重复 | 定界标记 + 哈希校验，逐字节一致才算合格 |
| 换主题要同步多页 | 只改真源，再整块替换所有分页的 STYLE-BLOCK，不逐页手改 |

### 3.2 三层契约

| 层 | 内容 | 约束 |
| --- | --- | --- |
| **令牌层** | `:root` 里的配色、字号阶梯、间距、圆角、最大宽度、字体栈 | 全演示的数值**只在这里出现一次**；正文一律 `var(--x)` |
| **骨架层** | `.slide` / `.slide-head` / `.slide-body` / `.slide-foot` + `data-role` 变体 | 所有页共用同一垂直对齐（`justify-content:center`），内容多少不会让标题在页间上下跳 |
| **组件层** | `.points`、`.grid`+`.card`、`.figure`、`.quote`、`.steps`、`table.data` | **白名单**，只能用这些 class；不新造、不写行内样式 |

三者共同保证：页与页之间**只换文字，不换版式**。

### 3.3 唯一真源：`pages/_template.html`

模板是一份可直接打开的完整 HTML5 文档，含：

- `<!-- STYLE-BLOCK:BEGIN -->` … `<!-- STYLE-BLOCK:END -->` 包住的整块 `<style>`；
- 设计令牌、骨架、六个受控组件、`data-role` 变体；
- 一段示范内容 + 顶部注释列出「复制后只改哪三块」；
- 末尾一条 `<!-- 引出下页：… -->` 注释，示范跨页承接。

文件名以 `_` 开头，`generate_index.py` 与 `serve.py --list` **都会自动忽略它**，不会污染放映清单，无需改任何代码。

### 3.4 换主题的正确流程

1. 只改 `pages/_template.html` 的 `:root`（必要时才动组件规则）。
2. 把新的 STYLE-BLOCK **整块**同步到所有已建分页（可用一段小脚本按定界标记替换）。
3. 跑 3.5 的哈希校验，全部 `OK` 才算完成。
4. 浏览器里逐页看一遍，含右键页码的缩略图面板。

**绝不允许**为了某一页「稍微调小一点字号」而单独改那一页的 style 块——这正是前后不统一的起点。确需变体，就回到模板里增加 `data-role` 或组件规则，再全量同步。

### 3.5 样式块一致性校验

项目已随附根目录 `check_style.py`（含退出码，可挂 CI），日常直接运行 `python check_style.py`。下面是它的核心逻辑；若要自行改写，**不要用 bash heredoc 直接粘贴，反斜杠会被吞**。没有定界标记的文件会列为 `SKIP`——现有 `slide-1..4.html` 是旧测试稿，未纳入本规范，属预期。

```python
import hashlib, pathlib, re

root = pathlib.Path('.')
pat = re.compile(r'<!-- STYLE-BLOCK:BEGIN.*?-->(.*?)<!-- STYLE-BLOCK:END -->', re.S)

tpl = (root / 'pages/_template.html').read_text(encoding='utf-8')
want = hashlib.sha256(pat.search(tpl).group(1).encode()).hexdigest()[:12]

for p in sorted((root / 'pages').glob('*.html')):
    text = p.read_text(encoding='utf-8')
    m = pat.search(text)
    if not m:
        print('SKIP  ', p.name, '(未纳入规范)')
        continue
    got = hashlib.sha256(m.group(1).encode()).hexdigest()[:12]
    print('OK    ' if got == want else 'DIFF  ', p.name, got)
```

出现 `DIFF` 即视为样式已漂移，必须整块同步后重跑。

## 4. 内容连贯方案

样式统一靠模板，内容连贯靠**写之前先定大纲**。Agent 不得直接开写第一页。

### 4.1 制作前先填页序大纲

| 序号 | 角色 | 唯一主张（一句） | 承接上页（一句） | 引出下页（一句） | 对应字幕句 |
| --- | --- | --- | --- | --- | --- |
| 1 | cover |  | — |  | 1–2 |
| 2 | agenda |  |  |  | 3 |
| 3 | content |  |  |  | 4–6 |
| … |  |  |  |  |  |

大纲先落定，再按行造页。每页 `lead` 写「承接上页」，末尾 HTML 注释写「引出下页」，两处与大纲逐字对应。

### 4.2 术语表先建

| 术语 | 统一写法 | 禁用写法 |
| --- | --- | --- |
|  |  |  |

整份演示里同一概念只能有一个叫法；改术语时全量替换，不允许某页沿用旧称。

### 4.3 跨页硬规则

1. **一页一个主张**，`h1` 只承载它；要点 3–5 条，不超一屏。
2. **标题句式统一**：要么全是名词短语，要么全是动宾，不要混着来。
3. `kicker` 写章节名，同章所有页一致；`slide-foot .doc` 整份演示一致。
4. 相邻两页必须有承接与引出，不允许「突然换话题」；换章用 `data-role="section"` 隔页。
5. 字幕与页是两套索引：大纲里写清每页对应 `subtitle.txt` 的第几句，避免放映时字幕与画面对不上。
6. 组件密度相近：连续两页不要一页全是列表、下一页全是卡片网格，观感会跳。

### 4.4 角色与组件对照

| 角色 | 用途 | 推荐组件 |
| --- | --- | --- |
| `cover` | 封面 | 仅 `slide-head`，`lead` 作副标题 |
| `agenda` | 目录 / 议程 | `.steps` 或 `.points` |
| `section` | 章节隔页 | 仅 `slide-head`（大字号变体） |
| `content` | 正文 | `.points` / `.grid`+`.card` / `.figure` / `table.data` |
| `summary` | 小结 | `.points` + `.quote` |
| `end` | 结束页 | 仅 `slide-head` |

## 5. 标准制作流程（SOP）

1. 读 `AGENTS.md` 第七节不变量 + 本文件第二部分。
2. 填**页序大纲**与**术语表**，确认每页角色、主张、承接/引出、字幕对应句。
3. 复制 `pages/_template.html` → `pages/<序号>-<页名>.html`。
4. 只改三处：`<title>`（与页名一致）、`<main>` 内文字、`slide-foot` 文字；按角色设 `data-role`。**STYLE-BLOCK 一个字不动**。
5. 删掉用不上的组件示例；不新造 class、不写行内 `style`、不写页码、不超一屏；末尾补「引出下页」注释。
6. 跑 `python generate_index.py`，再跑 `python generate_index.py --check`（退出码 0）。
7. 跑样式块校验 + 静态禁用项扫描 + 浏览器逐页实测（含缩略图面板）。

静态禁用项扫描：

```bash
grep -RIn -E '<script|https?://|style="|第[0-9一二三四五六七八九十]+页' pages/*.html
```

应无输出。模板的说明注释刻意不写这些关键字面，就是为了让这条扫描对模板本身和所有复制出去的分页都能直接生效。

## 6. 校验清单（改完必跑）

| # | 项目 | 命令 / 判据 |
| --- | --- | --- |
| 1 | 清单同步 | `python generate_index.py --check` → 退出码 0 |
| 2 | 生成物语法 | `node --check js/pages.js`、`node --check js/subtitle.js` |
| 3 | 样式一致 | `python check_style.py` → 退出码 0，新页全 `OK`、无 `DIFF`（旧测试稿为 `SKIP`） |
| 4 | 禁用项 | 上节 grep 无命中 |
| 5 | 模板不污染清单 | `python serve.py --list` 不出现 `_template.html`；`--dry-run` 的分页数不变 |
| 6 | 实际放映 | `python serve.py` → 逐页翻看版式一致、右键页码缩略图非全黑、无滚动条 |

> 项目反复验证过一条经验：**推理不算证据，采样才算**。涉及「页码对不对、样式一不一样、缩略图黑不黑」必须实际打开看，别只读代码下结论。

## 7. 常见错误速查

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| 给某一页单独调字号 | 页间视觉跳动 | 改模板 → 全量同步 |
| 页脚写「第 3 页」 | 插页后全错 | 页脚只放文档名 / 章节名 |
| 分页里放 `<script>` 想跟放映器通信 | 跨源失效、单独打开无宿主 | 不做通信；靠文件名与构建建立关联 |
| 用外链 CSS / 字体 | 离线打不开、单独发人掉样式 | 内联 STYLE-BLOCK + 系统字体栈 |
| 忘了写 `body` 背景 | 缩略图全黑 | 保留模板里的 `html,body{background:var(--bg)}` |
| 改完 `pages/` 不跑构建 | 新页不出现 | `python generate_index.py` |
| 手改 `js/pages.js` | 下次构建被覆盖 | 改文件名后跑构建 |
